## 三、主要功能和技术特点（不少于 800 字）

OpenCloudLab 云主机快速创建平台是一款面向功能测试场景的云主机自动化交付与生命周期管理系统，采用 Go 语言开发，以 OpenTofu（Terraform 兼容的开源基础设施即代码引擎）作为底层编排引擎，支持阿里云与火山引擎两家公有云厂商，实现云主机的"分钟级申请、按期自动回收"。

**（一）主要功能**

1. **飞书 OAuth 统一登录**。系统与飞书开放平台集成，用户点击登录后跳转飞书授权页，回调后由后端完成用户身份匹配与自动建户，签发 JWT 会话令牌；同时保留本地账号体系（bcrypt 密码哈希），支持双通道认证。
2. **PAT 个人访问令牌**。为命令行与自动化场景设计，用户可在网页上创建、查看、撤销形如 `pat_ocw_` 前缀的 Personal Access Token，令牌仅入库哈希值，泄漏可即时吊销。
3. **多云镜像与规格查询**。平台内置云提供商抽象层，统一封装阿里云与火山引擎的地域（Region）、镜像（Image）、实例规格（InstanceType）查询接口，用户在创建云主机前可先通过 REST API 查询可用资源，屏蔽不同厂商 API 差异。
4. **云主机一键创建**。用户指定云厂商、地域、可用区、镜像、规格与使用时长后，平台自动生成独立的 OpenTofu 工作目录（workspace），执行 `tofu apply` 完成资源创建，并在创建成功后回填公网/私网 IP。整个流程异步化，前端可轮询实例状态（Creating → Running）。
5. **TTL 生命周期管理与一次性续用**。每台云主机创建时即确定过期时间（ExpiresAt = 当前时间 + 申请时长），后台调度器每 30 秒扫描一次，对超期运行中的实例自动执行 `tofu destroy` 销毁并释放云资源；过期前用户可"续用"一次（每个生命周期仅一次），续用时长同样受配额上限约束，兼顾测试灵活性与资源回收确定性。
6. **管理员配额与用户管理**。管理员可设置全局单次最长使用时长上限，并可针对单个用户设置个性化上限（用户配额为 0 时回落到全局默认）；支持用户的启用/禁用、角色（管理员/普通用户）调整与删除。
7. **审计日志**。所有关键操作（登录、令牌管理、创建/销毁实例、用户管理等）均写入审计日志表，管理员可按时间倒序查询，满足企业内控与追溯要求。

**（二）技术特点**

1. **OpenTofu 动态编排**：平台不直接调用云厂商的购买/释放 API，而是为每个实例维护独立的 OpenTofu state 工作目录，按 provider 加载对应的 HCL 模板并注入变量。这种"一实例一工作区"的设计使资源创建与销毁完全声明式、可重放、状态可审计，天然避免了手工操作造成的资源泄漏。
2. **多云适配器架构**：通过 `Provider` 接口（ListRegions / ListImages / ListInstanceTypes）抽象云能力，新增云厂商只需实现一个适配器与一份 OpenTofu 模板，核心业务零改动。
3. **极简依赖与容器化交付**：全部代码仅依赖 Go 标准库与三个第三方库（JWT、bcrypt、纯 Go SQLite 驱动），存储采用无 CGO 的 SQLite 单文件数据库，多阶段 Dockerfile 构建出含 OpenTofu 的非 root 运行时镜像，docker compose 一键启动，数据目录挂载即持久化。
4. **安全设计**：JWT 与 PAT 双令牌认证、密码 bcrypt 哈希、PAT 仅存哈希、云 AK/SK 通过环境变量注入不落库、OAuth state 防 CSRF，全程 HTTPS 友好。
5. **可靠性**：调度器对销毁失败实例保留 Destroying 状态并记录错误信息，下轮自动重试；Creating 状态超时（默认 15 分钟）自动转 Failed，防止流程卡死。

综上，本软件将基础设施即代码、多云适配、配额治理与自动回收相结合，为测试团队提供安全、可控、免手工的云主机供给平台。

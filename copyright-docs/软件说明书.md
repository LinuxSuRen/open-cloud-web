# OpenCloudLab 云主机快速创建平台 软件说明书

（用户操作手册 / 设计说明书 · V1.0）

## 1. 产品概述

OpenCloudLab 是一款面向功能测试场景的云主机快速创建平台。它以 OpenTofu（Terraform 兼容的开源基础设施即代码引擎）为底层编排核心，对接阿里云与火山引擎两家公有云，为测试人员提供"分钟级申请、按期自动回收"的云主机供给服务。

平台解决的核心痛点：测试用云主机往往手工创建、忘记释放，造成云资源长期空跑浪费。OpenCloudLab 通过 TTL（存活时间）生命周期模型，让每台云主机从诞生起就带有明确的过期时间，到期由后台调度器自动销毁；确有需要时用户可"续用"一次，兼顾灵活与可控。

主要能力：

- 飞书 OAuth 统一登录，JWT 会话 + PAT 个人访问令牌双通道认证
- 多云（阿里云/火山引擎）地域、镜像、实例规格统一查询
- 声明式一键创建云主机，自动回填公网/私网 IP
- TTL 过期自动销毁，支持一次性续用
- 管理员配额（全局上限 + 用户级上限）、用户管理、审计日志
- docker compose 一键部署，SQLite 单文件存储，运维成本极低

## 2. 体系结构

```mermaid
flowchart LR
    U[用户/CLI] -->|HTTP /api/v1| API[internal/api\nREST API + 认证中间件]
    API --> AUTH[internal/auth\nJWT / PAT / 飞书 OAuth]
    API --> STORE[internal/store\nSQLite 持久化]
    API --> CLOUD[internal/cloud\n阿里云 / 火山引擎适配器]
    API --> TOFU[internal/tofu\nOpenTofu Runner]
    SUBGRAPH 后台
        SCH[internal/scheduler\nTTL 调度器 30s 扫描]
    end
    SCH --> STORE
    SCH --> TOFU
    TOFU -->|tofu apply/destroy| CLOUDAPI[云厂商 API]
    CLOUD --> CLOUDAPI
```

包职责（与 ARCHITECTURE.md 契约一致）：

| 目录 | 职责 |
| --- | --- |
| `cmd/ocw` | main 装配：加载配置、初始化 store/scheduler、注册路由 |
| `internal/config` | 环境变量配置（支持 `OCW_` 前缀） |
| `internal/model` | 领域模型：User、Instance、Image、InstanceTypeSpec、AuditLog 等 |
| `internal/store` | 存储接口 + SQLite（modernc.org/sqlite，纯 Go 无 CGO）实现 |
| `internal/api` | REST API、认证中间件、请求/响应模型 |
| `internal/auth` | JWT 签发校验、PAT 哈希管理、飞书 OAuth 流程 |
| `internal/cloud` | 云提供商抽象（镜像/规格/地域查询） |
| `internal/tofu` | OpenTofu 执行封装，一实例一 workspace |
| `internal/scheduler` | TTL 过期调度：续用一次、超时销毁、卡死转 Failed |
| `deploy` | Dockerfile、compose、entrypoint、tofu 模板 |

实例状态机：`Creating → Running → Destroying → Destroyed`；`Creating` 超时（默认 15 分钟）转 `Failed`，`Destroying` 失败保留状态并重试。

## 3. 安装部署

前置条件：Docker 20+ 与 docker compose v2；一个飞书企业自建应用；阿里云和/或火山引擎的 AccessKey。

```bash
git clone <仓库地址> open-cloud-web
cd open-cloud-web

# 写入环境变量（见 docs/deployment.md 完整参数表）
export OCW_JWT_SECRET="$(openssl rand -hex 32)"
export OCW_FEISHU_CLIENT_ID=cli_xxxx
export OCW_FEISHU_CLIENT_SECRET=xxxx
export OCW_PUBLIC_BASE_URL=https://ocw.example.com
export OCW_ALICLOUD_ACCESS_KEY=xxxx
export OCW_ALICLOUD_SECRET_KEY=xxxx
export OCW_VOLCENGINE_ACCESS_KEY=xxxx
export OCW_VOLCENGINE_SECRET_KEY=xxxx

docker compose -f deploy/compose.yaml up -d
curl http://localhost:8080/healthz   # 健康检查
```

数据全部落在挂载的 `data/` 目录（SQLite 数据库 + 各实例 OpenTofu workspace），升级替换容器不丢数据。

## 4. 用户流程

### 4.1 飞书登录

1. 浏览器打开平台首页，点击"使用飞书登录"。
2. 跳转飞书授权页，确认授权后回调平台。
3. 首次登录自动创建账号（provider=feishu），之后每次登录签发 JWT。

### 4.2 创建 PAT

CLI 调用需要 PAT。登录后进入"个人令牌"页面：

1. 点击"创建令牌"，输入名称（如 `my-laptop`），设置过期时间。
2. 令牌明文 **仅显示一次**（形如 `pat_ocw_xxxx`），请立即保存；数据库中只保留哈希。
3. 不再需要时点击删除即可吊销。

### 4.3 CLI 调用

```bash
TOKEN=pat_ocw_xxxx
BASE=http://localhost:8080/api/v1

curl -H "Authorization: Bearer $TOKEN" $BASE/me
```

### 4.4 查询镜像与规格

```bash
# 可用地域
curl -H "Authorization: Bearer $TOKEN" $BASE/providers/alicloud/regions
# 地域内镜像
curl -H "Authorization: Bearer $TOKEN" "$BASE/providers/alicloud/images?region=cn-hangzhou"
# 地域内实例规格
curl -H "Authorization: Bearer $TOKEN" "$BASE/providers/alicloud/instance-types?region=cn-hangzhou"
```

### 4.5 创建云主机

```bash
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/instances -d '{
    "provider": "alicloud",
    "region": "cn-hangzhou",
    "zone": "cn-hangzhou-i",
    "imageID": "aliyun_3_x64_20G_alibase_20240528.vhd",
    "instanceType": "ecs.e-c1m1.large",
    "durationSec": 7200,
    "name": "test-vm-01"
  }'
```

`durationSec` 可省略（用默认 3600 秒），上限为 `min(用户配额, 全局上限)`。创建异步进行，轮询 `GET /instances/{id}` 观察 `status` 从 `creating` 变为 `running`，成功后返回 `publicIP` / `privateIP`。

### 4.6 续用

到期前可续用 **最多一次**：

```bash
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/instances/42/renew -d '{"durationSec": 3600}'
```

续用后 `renewedAt` 置为当前时间，再次请求会被拒绝。如需提前释放：

```bash
curl -X DELETE -H "Authorization: Bearer $TOKEN" $BASE/instances/42
```

### 4.7 自动销毁

后台调度器每 30 秒扫描：`running` 且已过 `expiresAt` 的实例被置为 `destroying`，异步执行 `tofu destroy`，成功后转 `destroyed`，云资源彻底释放。销毁失败会记录错误信息并在下一轮重试。`creating` 状态超过 15 分钟自动转 `failed`。

## 5. 管理员流程

管理员（role=admin）使用与普通用户相同的登录入口，额外拥有管理能力：

1. **用户管理**：`GET /users` 列出全部用户；`POST /users` 手工建号；`PATCH /users/{id}` 可调整角色（role）、启停状态（status）以及单用户最长使用时长（maxDurationSec，0 表示使用全局默认）；`DELETE /users/{id}` 删除用户。
2. **配额设置**：全局上限由环境变量 `OCW_MAX_DURATION_SEC` 控制（默认 86400 秒）；用户实际上限 = min(用户 maxDurationSec, 全局值)，创建与续用时统一校验。
3. **审计日志**：`GET /admin/audit-logs` 按时间倒序返回登录、令牌管理、实例创建/销毁、用户变更等关键操作记录，便于追溯。

## 6. REST API 端点一览

前缀 `/api/v1`，除登录回调外均需 `Authorization: Bearer <jwt或pat_ocw_...>`。

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | `/auth/feishu/login` | 获取飞书授权跳转地址 `{authorize_url}` | 匿名 |
| GET | `/auth/feishu/callback` | 飞书 OAuth 回调，签发 JWT | 匿名 |
| POST | `/auth/token` | PAT 换取 JWT | 匿名（携带 PAT） |
| POST | `/auth/pats` | 创建 PAT | 登录用户 |
| GET | `/auth/pats` | 列出我的 PAT | 登录用户 |
| DELETE | `/auth/pats/{id}` | 删除（吊销）PAT | 登录用户 |
| GET | `/me` | 当前用户信息 | 登录用户 |
| GET | `/users` | 用户列表 | 管理员 |
| POST | `/users` | 创建用户 | 管理员 |
| PATCH | `/users/{id}` | 更新用户（role/status/maxDurationSec 等） | 管理员 |
| DELETE | `/users/{id}` | 删除用户 | 管理员 |
| GET | `/providers/{p}/regions` | 云厂商可用地域 | 登录用户 |
| GET | `/providers/{p}/images?region=` | 地域内镜像列表 | 登录用户 |
| GET | `/providers/{p}/instance-types?region=` | 地域内实例规格 | 登录用户 |
| POST | `/instances` | 创建云主机 | 登录用户 |
| GET | `/instances` | 我的实例列表 | 登录用户 |
| GET | `/instances/{id}` | 实例详情 | 登录用户 |
| POST | `/instances/{id}/renew` | 续用一次（可选 durationSec） | 登录用户 |
| DELETE | `/instances/{id}` | 提前销毁实例 | 登录用户 |
| GET | `/admin/audit-logs` | 审计日志 | 管理员 |

`{p}` 取值：`alicloud`、`volcengine`。

## 7. 故障排查

| 现象 | 可能原因与处理 |
| --- | --- |
| 登录后 401 | JWT 过期，重新登录；CLI 场景检查 PAT 是否被吊销 |
| 实例长时间 `creating` 后变 `failed` | 查看 `errorMessage` 字段；常见为 AK/SK 权限不足、镜像/规格在该可用区不存在、账号欠费 |
| 实例一直 `destroying` | OpenTofu destroy 失败，调度器会自动重试；查看实例 `errorMessage` 与容器日志中 tofu 输出 |
| 镜像查询为空 | 该地域无可用镜像，或云 AK 无只读权限；先用 regions 接口确认地域拼写 |
| 飞书回调报错 | 检查 `PUBLIC_BASE_URL` 与飞书后台配置的回调地址一致、`FEISHU_CLIENT_ID/SECRET` 正确 |
| 容器反复重启 | `docker logs` 查看启动错误；常见为 `JWT_SECRET` 未设置或 `MAX_DURATION_SEC < DEFAULT_DURATION_SEC` |
| 数据丢失 | 确认 compose 挂载了 `data/` 卷；升级前先备份（见 deployment.md） |

## 8. 安全说明

- JWT 密钥（`OCW_JWT_SECRET`）必须为强随机值，切勿入库入仓。
- PAT 明文仅在创建时展示一次，库中仅存哈希；疑似泄漏立即删除。
- 云厂商 AK/SK 仅经环境变量注入运行进程，不落数据库、不进前端。
- 飞书 OAuth 使用 state 参数防 CSRF。
- 用户密码使用 bcrypt 哈希存储。
- 生产环境应在平台前置反向代理并启用 HTTPS。
- 建议云 AK 遵循最小权限原则，仅授予 ECS 相关的创建/查询/释放权限。

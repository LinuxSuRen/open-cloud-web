# 源程序材料生成说明

## 目的

中国版权保护中心要求软件著作权登记提交源程序材料：**前后各连续 30 页**（每页 50 行），整个程序不足 60 页时全部提交。本文档说明本项目源程序材料的自动生成方式。

## 生成方式

执行仓库内脚本（无需额外依赖，仅需 bash + 常规 coreutils）：

```bash
./tools/gen_source_doc.sh
```

脚本逻辑：

1. **收集**：遍历仓库，收集全部 `*.go`、`*.tf`、`*.sh`、`Dockerfile*` 源文件；排除 `*_test.go`（测试代码不计入）、`vendor/`、`.git/` 及 `copyright-docs/` 自身。
2. **拼接**：按文件路径稳定排序依次拼接，每个文件前插入一行 `// ===== 文件: 相对路径 =====` 分隔标记；**删除所有空行**。
3. **分页**：每 50 行为一页，每页首行插入页眉：`OpenCloudLab云主机快速创建平台软件  V1.0  第X页/共Y页`。
4. **截取**：总页数 ≤ 60 时全量输出；> 60 时输出前 30 页与后 30 页，中间插入省略标记行。

## 输出文件

| 文件 | 内容 |
| --- | --- |
| `copyright-docs/源程序.txt` | 软著申请用源程序材料（带页眉、已分页） |
| `copyright-docs/源程序行数统计.txt` | Go（不含测试）/测试代码/`*.tf`/脚本分类行数统计，以及去空行总行数与分页页数 |

## 当前统计结果（V1.0 生成时）

- Go 源程序（不含 `*_test.go`、vendor）：约 **4100+** 行
- OpenTofu 模板（`*.tf`）：约 **270** 行
- 脚本（`*.sh`、`Dockerfile`）：约 **100+** 行
- 去空行后总行数约 **4100+** 行，按每页 50 行计约 **83** 页
- 提交材料为前 30 页 + 后 30 页（含分隔标记共 61 页）

> 代码仍在迭代时，提交申请前请重新运行脚本刷新上述数字与 `源程序.txt`。

## 注意事项

- 《源程序.txt》首页应以程序起始代码开头、末页以程序结束代码结尾，本脚本通过"整文件排序拼接 + 前后各 30 页截取"天然满足。
- 若申请表"源程序量"需填单一数字，以 `find . -name '*.go' | xargs wc -l` 的 total（扣除测试代码）为准，与《源程序行数统计.txt》一致。
